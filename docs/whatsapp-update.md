# WhatsApp class update

Trevor's text to paste into WhatsApp after a private student's class (see
CLAUDE.md, "Planilha dos alunos"). Fill it from the sheet and the student's
bookings; write it only in the language the student is learning, no
translation under it. Right under the brand line go the main site's address,
then the schedule app's, before any other link: WhatsApp previews the first
link, and both show Trevor's logo (Trevor, 2026-10-05). Leave out the
Meet link line when the student has none. Give the next class's time in the
student's own time zone only (the sheet's last column), e.g. "7:00 AM (Los
Angeles time)"; never Denver's unless they're in Denver (Trevor, 2026-10-05).
Name the zone by its big city, never the student's state or town (Trevor,
2026-10-19): New York, Chicago, Denver, Los Angeles, São Paulo; the sheet's
time zone column holds the same names (in Portuguese texts, Nova York).
`*text*` is bold in WhatsApp.
The package lines go last, bold and in capitals between rules, so no student
misses that a package has ended, in as few words as that takes (Trevor, 2026-10-12).
Whenever classes done reach the package (none left), add
under them "*⚠️ Your package has ended. Let me know if you'd like to renew!*"
("*⚠️ Seu pacote terminou. Me avise se quiser renovar!*").
Every package has one free cancellation, no questions asked (Trevor,
2026-10-18), starting with each student's next package: a package already
under way on 2026-10-18 has none, and when the student renews Trevor sends
them the "What I offer" documents (English and Portuguese) with the new
rules. The text never mentions it until it's used. When Trevor says a
student used theirs, write "Free cancel used <date>" in the sheet's Notas
column for that student (one per package; clear it when a new package
starts), send the free-cancel version that time (the regular text with the
thank-you line swapped for one saying the class didn't count and the next
late one would), and from then on, for the rest of that package, add
"*🎟️ FREE CANCELLATION: USED*" ("*🎟️ CANCELAMENTO GRÁTIS: USADO*") as the
last line in the package box. After it, a late cancellation (inside 24 hours
or missed, so it counts) gets the late-cancel version: the same text with
the thank-you line swapped for one saying the class counts.

## English, class moved

After a class is moved (by the student from the main site's header menu, by
a reschedule Trevor approved, or by Trevor canceling and booking the new
time), the regular text with the thank-you line swapped and the old time in
brackets under the new one. Trevor copies it from the student hub or the
lessons site's Notes panel; students never get it generated for them.

```
*English & Portuguese with Trevor*
https://englishandportuguesewithtrevor.com

https://schedule.englishandportuguesewithtrevor.com

Hi {name}! Your class has been moved 📅

📅 New time: {weekday}, {month} {day}, at {time} ({time zone})
(was {weekday}, {month} {day}, at {time})

🎥 Class link: {meet link}

See you then!

━━━━━━━━━━━━━━
*✅ CLASSES COMPLETED: {done} OF {package}*
*📦 CLASSES LEFT: {left}*
```
